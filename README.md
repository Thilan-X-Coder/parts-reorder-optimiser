# Parts Reorder Optimiser

Forecasts spare-part demand over the supplier lead time and converts that
forecast into a weekly reorder list a warehouse planner can act on.

**Dataset:** Online Retail II (UCI) — public proxy for a spare-parts issue history.
**Users:** Parts / warehouse planning team.
**Status:** EDA in progress.

## Workflow
- `notebooks/` — exploration only. No pipeline logic lives here.
- `src/` — the reproducible pipeline.
- Run all scripts from the project root.
